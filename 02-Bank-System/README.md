# 🏦 Console Banking & Currency Exchange System

## 📝 About The Project
A comprehensive, console-based banking management system built entirely in C++. This project demonstrates a strong understanding of Object-Oriented Programming (OOP) principles, modular design, and data management. It serves as a complete system to manage bank clients, users (employees), financial transactions, and currency exchange operations.

## ✨ Key Features

* 🔐 Security & Access Control:
  * Secure Login system for employees/users.
  * System logs to track user logins.

* 👥 Client Management:
  * Add, Delete, Update, and Find Clients.
  * View a comprehensive list of all bank clients.

* 💼 Banking Transactions:
  * Deposit and Withdraw funds.
  * Transfer balances between different client accounts.
  * View total balances across the bank.
  * Detailed transaction history screens.

* 👤 User (Employee) Management:
  * Manage bank employees with specific permissions.
  * Add, Delete, Update, and Find Users.

* 💱 Currency Exchange System:
  * Built-in functionality for managing and converting different currencies.

## 🛠️ Built With
* Language: C++
* Paradigm: Object-Oriented Programming (OOP)
* IDE: Microsoft Visual Studio

## 📂 Architecture
The project is highly modular, separating logic into distinct components:
* Screens: Handles the console UI and user inputs.
* Core Classes: Business logic for Clients (clsBankClient), Users (clsUser), and Currencies.
* Libraries: Custom utility classes for Date manipulation (clsDate), String operations (clsString), and Input Validation (clsInputValidate).
